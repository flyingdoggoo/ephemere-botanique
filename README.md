# ÉPHÉMÈRE // Haute Botanical Atelier & Sculptural Floristry

> Where botanical fragility transcends into sculptural permanence.

A world-class, ultra-luxury cinematic botanical landing page built with high-performance responsive engineering, Emil Kowalski spring lerp physics, sub-frame optical crossfade flower blooming, and editorial typography.

## Live Experience
- **Production URL**: [https://ephemere.oguri-lab.io.vn](https://ephemere.oguri-lab.io.vn)

## Highlights
- **305-Frame Real Rose Cinematic Bloom**: High-framerate HTML5 Canvas sequence with progressive hydration and sub-frame cross-dissolve.
- **Museum Curatorial Dossier**: Interactive fine-art folios with spring-physics modal views.
- **Living Botanical Ambient Light**: Organic color resonance system reacting to specimen interactions.
- **Performance Optimized**: Sub-2MB total initial payload, 100% WebP image pipelines, zero layout thrashing with `IntersectionObserver`, and 120 FPS continuous scroll.

## Architecture
- `index.html`: Clean, semantic HTML5 structure.
- `styles/`: 3-tier design token architecture (`tokens.css`, `typography.css`, `components.css`, `main.css`).
- `scripts/`: Modular performance engines (`real-rose-bloom.js`, `artistic-theme.js`, `floating-sanctuary.js`, `petal-physics.js`, `specimen-dossier.js`).
- `assets/`: Optimized WebP images and photographic sequence frames.
